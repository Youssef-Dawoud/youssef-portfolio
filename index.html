02 / Research

Master's Thesis

An OpenSSL Engine for Offloading Cryptography to Trusted Hardware on Industrial Gateways

OpenSSL ENGINE GlobalPlatform TEE Client API OP-TEE Arm TrustZone NXP i.MX7 / CAAM TLS 1.2 / 1.3 ECDSA / ECDH / X25519 RSA

My thesis builds on an existing OpenSSL engine that forwards an application's crypto calls through the GlobalPlatform TEE Client API, so applications get hardware-isolated cryptography with zero code changes. I extended it and moved it onto a real OP-TEE secure world (Arm TrustZone) on an NXP i.MX7 board, backed by the chip's CAAM crypto engine.

  • Extended the engine with ECDSA, ECDH, X25519, AES-GCM/CCM, ChaCha20-Poly1305, more hashes and an RNG, and wrote five new OP-TEE Trusted Applications.
  • Full TLS 1.2 and TLS 1.3 handshakes run in the secure world, with ECDSA and RSA server keys generated inside the TEE and never leaving it.
  • Found a bug in OP-TEE's CAAM RSA driver, present upstream since 2020, that kept it from using CRT keys. Fixed it on the board (RSA-2048 private operations 131 ms to 36 ms) and sent the fix upstream as OP-TEE pull request #8140, with issue #8139 reporting a related hang with CAAM-generated keys.
  • Validated with 129 automated checks on OP-TEE 4.8 and benchmarked against plain OpenSSL and Linux's own CAAM driver.

Supervisors: Prof. Luca Barbierato, Prof. Edoardo Patti, Ph.D. Tina Sayarmoafi, Politecnico di Torino
